# Base de demonstração — decisões e atendimento

> Cenários fictícios usados somente para demonstrar busca com fontes no Sinapse. Os prazos e valores abaixo não são políticas aprovadas da PRO4TECH.

## Decisão de histórico de solicitações

No cenário de demonstração, cada mudança de status de uma solicitação registra autor, data, status anterior, status novo e justificativa. Isso permite reconstruir o histórico do pedido.

## Prazo para análise urgente

No cenário fictício, uma solicitação urgente recebe a primeira análise em até 4 horas úteis. Esse prazo se refere somente à análise inicial; não é prazo de entrega nem de conclusão de todas as aprovações.

## Aprovação financeira

No cenário fictício, uma solicitação com valor estimado acima de R$ 5.000 exige aprovação adicional de Finanças.

## Como responder consultas

As respostas devem usar somente os trechos desta base e citar o documento de origem. Se a informação solicitada não estiver registrada, responder: “Informação não encontrada no acervo do projeto.”
