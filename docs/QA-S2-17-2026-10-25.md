## Reprodução

Na raiz, construir a imagem de dependências e executar os testes Python:

```bash
docker build -t sinapse-s209-ai-test ai-service
python -m unittest discover -s ai-service/tests -p "test_search*.py" -v
```

Em `backend`, com Python configurado no PATH ou informado por caminho absoluto:

```bash
npm run evaluate:search -- --python python --version 2 --rounds 3 --output ../ai-service/evaluation/results/s217-9936354-final
```

Artefatos locais ignorados pelo Git: `environment.json`, `summary.json`, `round-N-results.json`
e `round-N-metrics.json` em `ai-service/evaluation/results/s217-9936354-final/`.
Não contêm cookie, token, senha ou URL de conexão. O corpus contém somente documentação pública curada.

O preparo gera os vetores e marca os documentos da fixture como processados dentro do banco novo;
não mede upload/extração. Não acessa o banco de desenvolvimento. Banco e serviço IA foram removidos
ao final. O teste Python em contêiner foi repetido com o repositório e corpus montados juntos, após
uma primeira tentativa que montava somente `ai-service` e não encontrava a fixture.
