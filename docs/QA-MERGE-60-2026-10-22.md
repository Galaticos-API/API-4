## Falha confirmada — administração sem acesso pelo menu mobile

**Prioridade:** média, regressão de navegação responsiva.

**Código:** `frontend/src/App.tsx`, bloco `app-user-actions` e navegação do overlay mobile; `frontend/src/styles/layout.css`, media query `max-width: 960px`.

O botão `Abrir administração` existe no cabeçalho desktop para administradores. A media query oculta `app-user-actions`. O menu mobile substituto contém projetos, backlog, conhecimento e conversa, mas não contém ação administrativa.

**Reprodução autenticada em navegador:** criar administrador no banco isolado; abrir projetos em viewport desktop e confirmar o botão; mudar para 390×844; abrir o menu.

```json
{"case":"admin_navigation_mobile","role":"admin","desktop_admin_visible":true,"mobile_admin_visible":false,"admin_actions_in_mobile_menu":0}
```

O administrador ainda pode digitar a URL diretamente; não perdeu o papel nem a autorização da API. O problema é a ausência de navegação para a administração em dispositivos pequenos.

**Correção indicada:** incluir a ação administrativa no menu mobile somente para admin, fechar o overlay ao navegar e cobrir desktop/mobile e papéis sem privilégio.

**Estado:** corrigido localmente após a verificação. O menu mobile possui a ação Administração somente para admin, usando a navegação compartilhada que fecha o overlay ao trocar de página.
